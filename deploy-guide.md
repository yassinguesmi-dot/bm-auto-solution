# Guide de publication

## 1. Préparer le site
- Ouvrez le dossier du site dans votre navigateur ou sur un hébergeur statique.
- Les fichiers HTML/CSS/JS sont prêts à être publiés sans build.

## 2. Héberger
Vous pouvez publier sur :
- Netlify
- Vercel
- GitHub Pages
- tout hébergeur statique

## 3. Étapes rapides
1. Uploader tous les fichiers du dossier dans votre hébergeur.
2. Définir votre domaine personnalisé.
3. Activer HTTPS.
4. Vérifier les pages principales : Accueil, Services, Tarifs, Rendez-vous, Contact.

## 4. Évolution recommandée
Pour une version production complète :
- ajouter une vraie base de données
- connecter le formulaire de rendez-vous à un backend
- ajouter l’envoi d’emails automatisés
- sécuriser l’espace admin avec authentification réelle
